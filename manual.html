pj に戻る
章をタップすると開きます。 いつ・何をするかの順に並べました。 管理者だけの印が付いた操作は、 作業者用の端末では押せません（画面にも出ません）。
1. 毎日の作業
朝いちばん：MW の在庫CSVを取り込む
  • 画面の上の「MWの在庫CSVを取り込む」を押してファイルを選ぶ （仕入れタブ →「無在庫（eBay）」の中にある同じボタンでもよい）。
  • MW の在庫CSV は Shift_JIS・約12,200行。小分けにして送るので、 終わるまで画面を開いたままにする。ほかのアプリに切り替えると 通信が切れて「Load failed」になる。切れたら 「続きから送り直す」で途中から再開できる。
  • 取り込むと、MW で欠品した無在庫の出品は数量が自動で0になる。
  • 取り込みのたびに Discord に1通届く（6.151）。 その回に新しく動いたものだけが出る （在庫切れ＝eBay 無在庫は「数量0にしました」・ 仕入れる印は「注文前に売り切れました」／ 新入荷＝見込みあり・eBay 無在庫の候補）。 上位10件と、残りは pj の一覧へのリンク。 知らせる中身と件数は⚙で変えられる。
  • 取り込みの結果の「今回 新しく欠品 n行」はその回に 新しく消えたぶん、「欠品の合計」は欠品の印が付いている ぜんぶ。行は「JAN＋社」ごとなので、商品数（JAN）も添えて出る。
  • 前回の取り込み（日時・行数）は 仕入れタブの上と販売連携タブに出る。 24時間を過ぎると催促の帯が出る。取り込まないと MW の欠品が分からず、売り越しになる。
取り込んだあとにすること
  • 仕入れタブ（刈取）の「一覧を出す」で候補一覧を新しくする。
  • 「Amazonで調べる」を、残りが0になるまで押す 管理者だけ（→ 2章）。
  • 「仕入れる一覧」を開いて、仕入れる印を付けた行に 「MWで欠品」が出ていないか見る。欠品していたら印を外すか、 別の行に替える。
Discord の通知の見方
  • 🛒 MW に注文してください…… 無在庫（SKU が W- で始まる行）が 売れた。社・卸値・数量・注文の期限が出るので、MW に注文する。 注文すると2週間の取り置きになり、出荷時に銀行振込で決済する。
  • 売り越しの恐れ：…（FBA 0 / eBay n）…… FBA の在庫が0なのに eBay に出ている。2行目の「フェイズB：」に、数量0にするのか、 しないならその理由（手元在庫の印あり／入庫中／eBayのセール中／ 今回は動かさない／3回失敗 など）が出る。 理由が分かればその場で直せる（→ 4章の「印」）。
  • 📦 FBAで売れた：数量0 n件／再調達 n件…… フェイズBが eBay を 直した結果。「予定だけ表示」のときは、まだ変えていない。
  • 📥 MW の在庫CSVを取り込みました…… 取り込みのたびに1通。 在庫切れ（数量0にした・注文前に売り切れた）と新入荷が入る（6.151）。
  • 🔁 在庫補充（数量を1に戻す）…… eBay で売れて数量0になった行を、 売れた値段のまま1に戻す。「確認してから」のときは、 販売連携タブのボタンを押すまで動かない 管理者だけ。
  • ほかに eBayで売れた（自己発送かマルチチャネルかが出る）・ 納品待ちの商品がeBayに出ています・ 返送で手元に戻ります（売上ではない）などが届く。
やらないこと
  • 出品は終了しない。数量0で残す。終了すると ItemID が消えて、 同じ出品に積み直せない（→ 4章）。
2. 仕入れ（刈取：MW から仕入れて FBA で売る）
MW で仕入れて、 国内 Amazon の FBA で売るための調べもの。 eBay の無在庫（→ 3章）とは別で、こちらは実際に仕入れる。
① Amazonで調べる 管理者だけ
  • 1回押すと ①ASIN引き → ②出品の可否 → ③価格・手数料の順に進む。 持ち時間は①10秒・②5秒・③40秒（前の段が早く終われば次の段へ回る）。
  • 1回で進むのは、③価格が60件ほど（10秒に1回・20件ずつ）、 ②可否が20件。残りがあれば「もう一度押すと続きます」と出るので、 残りが0になるまで押す。
  • ランキングと Amazon の商品名は3日ごとに引き直す。値段も3日で取り直す。 引き直せなかった行は前の ASIN をそのまま使う（①の行に件数が出る）。
  • 夜中3時前後（日本時間）は避ける。自動値下げなどの日次処理が その時間に動く（3時間ごとの取り直しは毎時07分台、 MW の自動の取り直しは毎時37分）。
② 一覧の見方
  • 先頭の太字は粗利（税抜）。既定はせどりすと方式（粗利×0.9） （⚙設定で変えられる）。かっこの中が税込の粗利と利益率。
  • 手数料は Amazon から商品ごとに取った実際の値 （販売手数料・手数料消費税・FBA手数料）。取れていない行は 「仮の手数料」と出るので、そのまま信じない。
  • ランキングは大分類（ホビー・ゲームなど）で、 せどりすと と同じ数。小分類は小さく添えるだけ。 例：948,040位（ホビー）／小分類 11,481位。
  • 並べ替えは 粗利（税抜）／利益率／ランキング順／ジャンルごと。 絞り込みは 出品できる行だけ／利益率がこれ以上／ ランキングがこれ以下（0 なら見ない）など。
  • 出品の可否は 緑＝出せる・ 黄＝許可が要る（申請リンクが出る）・ 赤＝出せない・灰＝未調査。 赤には「仕入れる」を付けられない。調べ直しは緑が30日、 それ以外は7日。
  • JAN重複（要確認）…… 同じ JAN に Amazon の商品が2つ以上あるとき。 自動では決めないので、候補（MW の商品名に近い順）から 正しい ASIN を選ぶ。選ぶまでは仕入れと登録の対象から外れる。 「JAN重複（要確認）だけ表示」で絞れる。
③ 仕入れる印 → 注文
  • 行の「仕入れる」に数量を入れる。下の帯に件数・合計と 送料無料（¥50,000）まであと ¥n が出る。
  • MW の送料は1回 ¥880（5万円以上は無料）。取り置きでまとめて5点にすると 1点 ¥176 になるので、仕入値は卸値×1.1＋1点あたりの仕入れ送料で 計算している。
  • 「仕入れる行の JAN をコピー」…… JAN だけを改行区切りでコピー。 「注文用CSV」…… 数量・JAN・社・商品名・卸値・小計・合計の入った CSV。
  • できたら吉田さんに注文を頼む。注文すると2週間の取り置きになり、 出荷時に銀行振込で決済する。
④ 届いたら Amazon に登録
  • 「Amazon登録用ファイルを作る」…… せどりすと に取り込める TSV を書き出す（いままでの流れ）。
  • アプリから直接登録するときは 「Amazon に登録する（確認してから）」。確認画面で 件数・SKU・ASIN・売値を見てから、まず「1件だけ送る」。
  • 作業者の端末でも登録できる（6.151）。対象は 「仕入れる」の印が付いた商品だけ。 売値・SKU（仕入日・仕入原価）・電池や危険物の申告は pj-sync が決めるので、作業者は変えられない。 仕入日は印を付けた日、仕入原価は印を付けた時点の卸値。 MW から届く前でも、MW で売り切れた商品（仕入れ済みの区分）でも 登録できる。同じ ASIN で mw から始まる SKU がすでにあれば登録しない。
  • 1日の件数は⚙の「1日の登録の上限」（既定30件）まで。 誰がいつ何を登録したかは⚙の「登録の記録を見る」で見られる。
  • セラーセントラルの在庫管理でその1件が出ているか確かめる。 よければ「残りをまとめて送る」。結果は行ごとに出る。
  • 納品（箱詰め・ラベル・納品プラン）はセラーセントラルで行う。 価格改定はマカド。マカドは納品が完了してから反映される。
⑤ 自動の取り直し（⚙設定） 管理者だけ
  • ⚙設定の「Amazon刈取（国内FBA）」→「MW候補の Amazon 価格 （手数料・可否）を自動で取り直す」。既定はオン・1時間に100件 （6.149）。毎時37分に、JAN→ASIN の引き当て・価格と手数料・ 出品の可否を、選んだ件数ぶんだけ取り直す。 優先順は①見込みあり ②写真あり ③その他。
  • これはAmazon 側を取り直すだけ。 MW の在庫CSVの取り込みは手動のまま。
⑥ MW の写真を半自動で取り込む（ブックマークレット）
  • なぜ半自動か：MW の会員サイトをpj が勝手に見に行くことはしません （MW の許可が出るまでこの方針のままです）。 人が開いたページだけを読んで pj に渡します。 ID・パスワードは pj に持ちません（ログインはふだんどおり自分でします）。
  • 使う流れ：一覧の行の「MW で検索」を押す → Safari で会員サイトの JAN 検索が開く（必要ならログインする） → 商品が出たらブックマークレットを押す → 「コピーしました」と出る → pj に戻って、仕入れタブ（刈取）の 「MW の写真を貼り付けて取り込む」に貼り付け → 「取り込む」を押す。
  • ホーム画面の pj（アプリ）から押したときは、MW が Safari で開くようにしています（アプリの中のブラウザでは ブックマークが使えないため）。それでもアプリの中で開いたときは、 下の共有ボタン（□に↑）から「Safariで開く」を押してください。
  • 複数まとめて貼れます（改行か | で区切り）。 何件か続けて集めてから、まとめて取り込んでもかまいません。
  • 一覧の画面からまとめて取り込めます（6.135）。MW の 詳細検索で「新品」→機種→件数 100で検索します。
  • 商品が並んだらブックマークレットを押すと、 そのページの商品ぜんぶの「JAN:商品番号」がコピーされます （No Image の商品は飛ばします）。
  • pj に戻って貼り付け、次のページをめくってまた押す、の繰り返しです。
  • pj は、貼られた JAN のうち候補にある行だけを取り込みます。 候補に無い JAN とすでに写真がある JAN は飛ばし、件数だけ出します。
  • 100件まとめると5分ほどかかります。進み具合（n/N）と 残りの見込みを出します。
  • 「止める」でいつでも中断できます。残りは覚えているので、 閉じても次に「続きを取り込む」で再開できます。
  • 写真は長辺 500px 以上のものだけ使えます。 取り込んだあとは出品CSVタブの候補の行の「写真」に控えが入ります。
  • 同じ JAN で複数の社が出たときは、その JAN の写真をまとめて渡します。 検索した JAN と違う商品は渡しません。 JAN が分からない画面（一覧など）では何も渡しません （「JAN で検索した画面で押してください」と出ます）。
  • 作業者用の端末でも取り込めます（写真はもともと作業者の仕事です）。
⑥-2 ブックマークレットの入れ方（iPhone の Safari）
  • 1. pj の⚙設定 →「Amazon刈取（国内FBA）」→ 「ブックマークレットをコピー」を押す （コピーできないときは「中身を見る」で出た欄を長押しして全部コピー）。
  • 2. Safari でどれでもよいので1ページを開き、 下の共有ボタン（□に↑）→「ブックマークを追加」。 名前を「MWの写真」にして保存。 場所は「お気に入り」にしておくと、あとで押しやすくなります。
  • 3. 下のブックマークのボタン（本のアイコン）→ 「編集」→ いま作った「MWの写真」をタップ。
  • 4. アドレスの欄（http… と書いてあるところ）を全部消して、 1. でコピーした中身を貼り付ける （javascript: で始まる1行です）。完了を押す。
  • 5. 使うときは、会員サイトの検索結果のページで アドレス欄をタップ→「お気に入り」から 「MWの写真」を押します。
  • 鍵（キー）はブックマークに入りません。 ブックマークレットは文字をコピーするだけで、 pj には何も送りません（送るのは pj の側です）。
  • 「コピーしました」が出ないときは、画面に出た枠を長押しして 「コピー」を選んでください（iPhone がコピーを許さないことがあります）。
  • うまく動かないときは、 「javascript:」が消えていないか（貼り付けで消えることがあります）、 JAN で検索した画面（/buy/?q=…）で押しているかを確かめてください。 スタートページや新しいタブでは押せません （「スクリプトを実行できません」と出ます。ページを開いてから押します）。
3. eBay 出品（出品CSVタブ）
① せどりすとCSVを取り込む
  • 「せどりすとCSVを取り込む」でファイルを選ぶ（Shift_JIS）。 eBay出品用に書き出したファイルを使う。
  • 同じ ASIN ＋状態の行はまとめる（数量を足し、仕入値は高いほうに合わせる）。
  • SKU が空のファイル（仕入れ登録前のリスト）も取り込める。 「仕入れ前の候補」として M-<ASIN>・無在庫で入り、 仕入値は Amazon の基準価格を仮で使う。仕入れたら入れ直す。
② 英題と出品文
  • 「英題と出品文を一括作成」を押す（英題は pj-title が作る）。
  • 80文字を超える行・キャラクター名が取れない行は赤い指摘が出る。 行の欄で直せる。
  • 手で直した行は「作り直す」でも上書きしない。
③ 写真・原産国・カテゴリ
  • 行の「写真」から選ぶ（R2 に上げて公開URLを行に付ける）。 長辺500px以上の写真を使う（小さいと eBay が弾く）。
  • フィギュアは原産国とカテゴリ（可動 261068／非可動 261055）を選ぶ。
④ 書き出して File Exchange
  • 「CSVを書き出す（カテゴリごと）」。不備のある行は外れる （理由は行に出る）。
  • 出品は W2000（再調達用）で出し、「即発送」の印がある行だけ W1000。
  • eBay の Seller Hub → File Exchange でアップロードする。
⑤ 結果ファイルの取り込み
  • 「アップロード結果を取り込む」で eBay の結果ファイルを選ぶ。 Success の行は ItemID を記録し、Failure の行はエラーを行に出す。
  • そのあと販売連携タブの「出品リストの名簿を送る」を押す。 これで出品リストを空にしても、販売連携タブで値付けを動かせる。
  • 結果を取り込むまでカードを消さない。 書き出したのに ItemID が入っていない行には 「ItemID 待ち（消さないでください）」の印が付き、 「リストを空にする」でも残る。 うっかり消しても、結果の取り込みでゴミ箱から戻して結び付ける （ゴミ箱は30日・300件まで）。
中古フィギュアは自動で一点物
  • 和名に 特典・付き・付属・限定・初回・サイン・非売品・同梱などが 入る行は一点物（売れても買い直せない）として扱い、 自動値下げや再調達から外す。
  • 違っていたら、行の印（または販売連携タブの「一点物 オフ」）で直せる。
MW の eBay 無在庫
  • 出品CSVタブの「マッチングワールド（MW）の無在庫」。 Amazon で利益が出るかに関係なく出すので、Amazon刈取とは別に扱う。
  • 「eBayの相場を調べる（JANで検索）」…… 即決の出品の 最安値（送料込み）を控える。一度調べた JAN は7日間 調べ直さない。残りが出たら押し直す。
  • 「候補一覧を取り込む」→ 行に写真を付ける。 MW が利用を許諾した画像だけを使う（Amazon の画像は使わない）。
  • 「写真が付いた出品候補を出品リストに入れる」→ あとは ②〜⑤と同じ流れ。
  • 配送ポリシーはMW 用のもの（⚙設定「MW用の配送ポリシー名」・ 既定 W2000）。無在庫なので、売れてから仕入れる（→ 1章の通知）。
  • 仕入れ値は「MW と Amazon の安いほう」（6.152）。 MW（卸値×1.1＋仕入れ送料）と Amazon の新品最安値（送料込み）を 比べて安いほうで売値を決める。行に 「仕入れ基準：Amazon ¥○○」と出る。 Amazon の値段は24時間以内に取れた値だけ使う。 ⚙の「Amazon の値段も仕入れ値の候補にする」で切れる （既定オン）。
  • 重さは Amazon の梱包重量を使う（6.152）。 同じ JAN の ASIN があれば、その梱包重量＋⚙の梱包マージンで 送料を計算する。無ければ商品の重量、それも無ければ既定値 （フィギュア400g・ゲーム150g）。カードの「計算の詳細」に どこから取った値かが出る。手で直した重さはその値を優先する。
  • 売れたら Discord に「仕入れてください」が届く（6.152）。 その場で両方の値段を取り直し、安いほうを知らせる。 Amazon が安ければASIN・値段・URLと届け先：自宅、 MW なら届け先：秋葉原。 どちらでも下限利益を割るときは 🔴 が付くので、 買う前に確かめる。
4. 販売連携（売れたとき）
商品を探す
  • 一覧の上の検索欄で商品名・ASIN・JAN・ItemID・SKUから探せる。 📷でバーコードも読める。絞り込みと一緒に使える。
  • 「今日やること」…… 対応が必要／FBAで売れた／値下げの時期 （自動値下げがオンなら「自動値下げの予定」）／FBA納品の判断。 押すとその絞り込みになる。
FBA で売れたとき（フェイズB） 管理者だけ
  • FBA の販売可能が0になった行の eBay を数量0にする。 買い直せる行は数量0にして再調達の予定に入れる。
  • ⚙設定の「FBAで売れたときの動作」。 はじめは「予定だけ表示」で1日見てからオンにする。
  • 対象から外れる行：手元在庫の印あり／入庫中／eBayのセール中／ 今回は動かさない／3回失敗。理由は行と Discord の 「売り越しの恐れ」に出る。
eBay で売れたとき
  • 通知に自己発送（手元から送る）かマルチチャネル （Amazon で注文して送る）かが出る。
  • 数量0になった行は「在庫補充（数量を1に戻す）」で、 売れた値段のまま1に戻す 管理者だけ。 一点物・セール中・無在庫の行は戻さない。
  • 在庫で補充できるのは FBA の販売可能数か行の 「手元の数」が1点以上あるときだけ。 「手元在庫」の印だけでは補充しない （印は名簿を送るたびに自動で付き、売れても下りないので、 残っているか分からない）。手元にまだあるときは行の 「手元の数」を入れる（売れたら自動で減る）。
  • 予定の知らせ（Discord）は同じ予定なら1日1回。 行が増えた回と、24時間たった回は出る。
MW 無在庫（W-）の行
  • CustomLabel が W-<JAN> の出品も販売連携に入る。 カードの計算の詳細に 「仕入れ基準：MW ¥○○／Amazon ¥○○」と 「重量 ○○g（出どころ）」が出る。
  • 重さは手で入れた値→Amazon の梱包重量＋梱包マージン→ ジャンルの既定値の順。 仕入れ値は安いほう（Amazon の値段は24時間以内のものだけ）。
  • MW で欠品した行は赤で出て、段取り D が数量0にする。
取り込めなかった出品と、手で結び付ける
  • 「解析不可の出品」の箱に、読めなかった CustomLabel の 形ごとの件数と例が出る （空／W- の桁違い／E-・M- の崩れ／Amazon 用の SKU／ せどりすとの SKU／JAN だけ／その他）。
  • 読める形は E-<ASIN>／-U・-C・-L／ M-<ASIN>／W-<JAN>。
  • 取り込みで入らない出品は 「出品を手で結び付ける」に ItemID を入れて押す。 eBay を1件だけ読むだけで、eBay には何も書き込まない。 eBay 側の CustomLabel が空のときは、結び付ける先も入れる。
一点物と手元在庫の印
  • 手元在庫の印は「出品リストの名簿を送る」で付く （FBA に在庫がある行には付かない）。 この印がある行はフェイズBが動かさない。
  • 付け忘れ・付け間違いは、一覧で行を選んで下の帯の 「印を付ける ▾」から直す（一点物／無在庫／値下げしない／ eBay優先 の オン・オフ）。押した直後の帯の「元に戻す」で戻せる。
  • 手元在庫の印をまとめて付け直すときは 「手元在庫の印を付け直す」 管理者だけ。
出品は終了せず数量0で残す
  • 終了すると ItemID が消えて、同じ出品に積み直せない （見られた回数も消える）。在庫が戻ったら数量を1に戻すだけでよい。
  • 手で終了してしまった行は、売値や数量を直そうとしたときに 「終了している出品かもしれません」と出る （在庫補充の知らせにも「出品が終了していた n件」と出る）。 出し直すときは出品CSVから新しく出す （ItemID は別のものになる）。
5. 困ったとき
版の確かめ方と更新
  • いまの版はヘッダーの黄色い帯のタイトルの横に出る （v＋数字）。問い合わせのときはこの番号を伝える。
  • 新しい版が届くと、横に「更新があります（タップで再読み込み）」 と出る。タップすると読み込み直して新しい版になる。
  • 出ないときは、ブラウザを閉じて開き直す（ホーム画面のアプリは 前の画面がそのまま出ることがある）。
よく出るエラーと対処
  • 取り込みで「Load failed」…… 送っている間にアプリを切り替えると 通信が切れる。画面に戻って「続きから送り直す」。 取り込み中は画面を開いたままにする。
  • 「pj-sync のURLとキーを⚙設定に入れてください」…… ⚙設定の「接続設定（URL・キー・トークン）」を入れる。
  • 可否が全部「失敗」…… 行に HTTP の番号と Amazon の エラーコードが出る。失敗が続くときは途中で止まる。
  • wrangler の「Authentication error [code: 10000]」「7403」…… npx wrangler login をやり直す 管理者だけ。 マイグレーションは node d1-exec.mjs <SQLファイル> で流す （--file を使わず1文ずつ流すので、途中で失敗しても そのまま流し直せる）。
デプロイの手順 管理者だけ
  • ① git pull …… 新しいコードを取る。
  • ② マイグレーション（ある版だけ）…… cd proxy-sync → node d1-exec.mjs migrate-00NN-….sql。
  • ③ npx wrangler deploy …… Worker を入れ替える。
  • 順番を変えない。マイグレーションは必ずデプロイの前。 逆にすると、新しい列が無いまま Worker が動いて落ちる。
