# eBay 値付け計算機 (PWA)

Play Japan / 有限会社オーシャン貿易 の eBay 輸出向け価格計算ツール。
スマホのホーム画面に追加すると、全画面のアプリとして動きます。圏外でも動作します。

## 置き場の決まり（npm・設定）

リポジトリのいちばん上に `package.json` と `package-lock.json` を置き、
**`node_modules/` は入れない**（`.gitignore`）。

```powershell
git clone …
cd pj_price
npm ci            # package-lock.json のとおりに入れる（版が固定される）
```

* `wrangler` は**いちばん上に1回だけ**入れる。`node_modules` は上の階層へ
  たどって見つかるので、`proxy-sync` など各 Worker の場所からも使える
* 版は `package.json` で**固定**（`^` や `~` を付けない）。
  上げるときは `npm i -D wrangler@<版>` を流して lock ごとコミットする
* **`package.json` に `"type"` を書かない。**
  `"type":"module"` にすると `tests/*.js`（CommonJS）が全部壊れ、
  `"type":"commonjs"` にすると Node の ESM の自動判別が止まって
  `proxy-sync/worker.js`（`export default`）を読めなくなる
* よく使う命令

  | | |
  | --- | --- |
  | `npm test` | テストをぜんぶ流す |
  | `npm run d1 -- proxy-sync/migrate-0031-….sql` | マイグレーションを1文ずつ流す |
  | `npm run d1:all` | **未適用のマイグレーションだけ**を番号順に流す（7.116） |
  | `npm run d1:all -- --dry-run` | 流すものの一覧だけ出す（何も変えない） |
  | `npm run deploy:sync` | pj-sync を出す（`:price` `:img` `:title` も） |

**出先（スマホ）から pj-sync を出すとき**は、GitHub の **Actions** タブの
**deploy-pj-sync** を押す（D1 のマイグレーションとデプロイをまとめて行う・7.116）。
手順と Secrets の登録は `proxy-sync/README.md` の **1-7**。
**画面（`index.html`・`sw.js`・`manual.html`）は GitHub Pages なので、
main に push した時点で自動で出る**（この操作は要らない）。

**Worker の設定（`wrangler.toml`）**：KV の id は**秘密ではない**ので
リポジトリに入れる（それだけでは誰も読めず、読み書きにはアカウントの認証が要る）。
入れておかないと、手元で書き換えるたびに `git pull` でぶつかる。
**秘密（APIキー・トークン・パスワード）は `wrangler secret put` で入れ、
`[vars]` にもリポジトリにも書かない。**

## 公開手順（GitHub Pages）

このアプリはリポジトリ **`pj_price`**（Public）で公開済みです。GitHub Pages は有効です。

- 公開URL: **https://gamegamesan-dot.github.io/pj_price/**
- 設定: **Settings → Pages** で Source = **Deploy from a branch**、Branch = **main / (root)**

ファイルを差し替えて `main` に push すると、1〜2分で公開URLに反映されます（あわせて `sw.js` のバージョンも上げること。下記「更新のしかた」参照）。

Service Worker は HTTPS が必要です。GitHub Pages は HTTPS なのでそのまま動きます。

## 更新のしかた

`index.html` などを差し替えたら、`sw.js` の2行目
```js
const V = 'pj-pricing-v5';
```
の末尾の番号を `v6`, `v7` … と上げてください。これを変えないと古いキャッシュが残り続けます。
（`pj-pricing` はキャッシュ名の接頭辞で、リポジトリ名 `pj_price` とは別物です。変更不要）

**あわせて `index.html` の `var APP_V='vNN'` も同じ番号にしてください。**
こちらは「いま画面に出ている HTML 自身の版」で、フッターに出るのはこの値です。
2つがずれていると、画面が古いままなのに新しい版だと思ってしまいます
（番号がそろっているかは確認用の `ver.js` が見ています）。

### 直したあとの作業の書き方（7.116）

直したあと、何をすればよいかは次の3つに分けて書く。

| 変えたもの | 作業 |
| --- | --- |
| 画面（`index.html` / `sw.js` / `manual.html` / `shared/pricing.js` / `shared/mwcsv.js`） | **main に push すれば GitHub Pages が自動で出す**（操作は要らない。スマホの画面は再読み込み） |

PC が使えるときは今までどおり
`cd proxy-sync; node d1-migrate.mjs; npx wrangler deploy` でもよい
（どちらで流しても二重にならない）。

## 確認用テスト

`tests/` に入れてあります。**直す → テストを足す → push** の順で進めます。
以前は作業用の一時フォルダに置いていて、実行環境が入れ替わったときに消えました。
リポジトリに入れてあるので、どの端末でも同じコマンドで走ります。

### 走らせ方

```sh
sh tests/run.sh            # すべて
sh tests/run.sh review     # 名前に review を含むものだけ
node tests/review.js       # 1本だけ（中身の出力も全部見える）
```

`❌` が1つでもあれば終了コードは 1 になります。

### 必要なもの

| もの | 備考 |
|---|---|
| Node 22 以上 | `node:sqlite`（Worker のテストで D1 の代わりに使う）が要るため |
| Playwright と Chromium | 画面のテスト（`*.js`）で使う。`npm i -g playwright && npx playwright install chromium` |

置き場所は `tests/lib.js` が自動で探します。見つからないときは
`PJ_CHROME=/path/to/chrome sh tests/run.sh` のように Chromium の場所を渡してください。
`PLAYWRIGHT_BROWSERS_PATH` が設定されていればその中も見ます。

### 値付けの式を変えるとき

`tests/pricing.js` と `tests/pricing.mjs` は、`tests/pricing-baseline.json`
（**式を変える前**に記録した金額）と1セント単位で見比べます。
式をわざと変える（手数料の実測値を直す、地帯を増やすなど）ときは、
**変える前に**基準を取り直してください。

```sh
node tests/tools/record-baseline.js     # tests/pricing-baseline.json を作り直す
```

`tests/tools/` は一括実行（`sh tests/run.sh` が見るのは `tests/*.js` と `tests/*.mjs`）
には入りません。**いまのコードで取り直すと見比べる意味が無くなる**ので、
うっかり走らせないようここに置いてあります。

## 会員向け Discord サーバーを作る（8.1）

サブスク会員に商品リストを配信するための Discord サーバーを、ボットで自動で作ります。
**社内用の通知サーバー（pj-sync が投げる先）とは別のサーバー**です。
設計は `discord/server.config.json` にぜんぶ書いてあります（直して再実行すれば変わります）。

### 1. ボットを作る

1. <https://discord.com/developers/applications> を開き、**New Application**（名前は `pj 配信ボット` など）
2. 左の **Bot** → **Add Bot** →（必要なら）**Reset Token** を押して**トークンをコピー**
   - トークンは**パスワードと同じ**。人に見せない・ファイルに書かない・チャットに貼らない
   - **特権インテント（Message Content など）はオフのまま**でよい（このスクリプトは使いません）
3. 左の **OAuth2 → General** で **Client ID** をコピー

### 2. 招待する（必要な権限だけ）

次の URL の `（Client ID）` を差し替えて開き、**作ったサーバーを選んで招待**します。

```
https://discord.com/api/oauth2/authorize?client_id=（Client ID）&scope=bot&permissions=268561424
```

入っている権限は **チャンネルの管理・ロールの管理・メッセージの送信・メッセージの管理（ピン留め）
＋チャンネルを見る・履歴を読む・リンクの埋め込み・ファイルの添付** の8つだけです。

招待したら、**サーバーの設定 → ロール**で、ボットのロールを
**「管理者」より下・会員のロールより上**に置いてください
（ボットは自分より上のロールを触れないため）。

### 3. サーバー ID を調べる

Discord の **設定 → 詳細設定 → 開発者モード**をオンにし、
サーバー名を右クリック → **サーバーIDをコピー**。

### 4. 実行する（PowerShell）

```powershell
cd C:\…\pj_price
$env:DISCORD_BOT_TOKEN="（コピーしたトークン）"
$env:DISCORD_GUILD_ID="（コピーしたサーバーID）"

node discord/setup-discord.mjs --dry-run   # 1. 何をするかだけ見る（変えません）
node discord/setup-discord.mjs             # 2. 実行する
node discord/setup-discord.mjs             # 3. もう一度（「なし」ばかりになるのが正しい）
```

- **何度実行しても二重に作りません**（名前で照合し、あれば権限と並び順だけそろえます）
- **既存のチャンネル・ロール・書き込みは消しません**。設定に無いものは
  「設定にないもの（消していません）」として一覧に出すだけです
- 案内文（#はじめに・#ルール・規約・#お知らせ）は**空のチャンネルにだけ**投稿してピン留めします
- 実行後に **`discord/ids.json`** にロールとチャンネルの ID を書きます
  （あとで pj からの配信やロール付けに使います。`.gitignore` に入れてあるので公開されません）
- まず**テスト用のサーバー**で 1 → 2 → 3 を試してください

```
R = 為替レート（円/USD）

■ 米国関税・通関手数料（米国宛 = zone 4 のときだけ加算。非US は 0）
  出典: 2026-09-05 に Zonos Prepay アプリで実測（制度変更で変わる）
  関税率 d      = 0.1374（zone 4）/ 0（それ以外）   ← 関税12.5% + 通関手数料の変動分1.24%
  固定 fixed_us = ¥562 （zone 4）/ 0（それ以外）    ← 通関手数料の固定分
  米国関税額 = 申告額 × 0.1374 + ¥562   （申告額 = 売値 × R。zone 4 のみ／非US は 0）
    例: 申告額 5,000円 → ¥1,249 ／ 10,000円 → ¥1,936（固定562があるため少額ほど負担が重い）

a = R × (1 − 手数料率 − 為替コスト率)
b = R × d
固定計 = 固定手数料 + fixed_us

利益 = 売値×(a − b) + 請求送料×a − 固定計 − 仕入 − 梱包 − 実送料
売値 = (目標利益 + 固定計 + 仕入 + 梱包 + 実送料 − 請求送料×a) / (a − b)
```

「Best Offer 自動拒否ライン」は目標利益 0 のときの売値です（＝損益分岐価格）。米国宛はこの関税分だけ分岐点が上がり、非US（アジア等）は加算されないぶん下がります。
